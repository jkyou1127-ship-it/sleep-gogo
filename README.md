# 슬립 퀘스트 (Sleep Quest)

수면 기록을 게임처럼 관리하는 웹앱. 매일 취침/기상 시각과 컨디션을 기록하면
포인트를 얻고, 포인트로 배지를 모으고 레벨을 올리고, 모은 포인트를 적립금(원)으로
전환할 수 있어요.

## 기능

- **로그인 / 회원가입** — 이메일 + 비밀번호 (닉네임 설정 가능)
- **오늘의 체크인** — 화면 끈 시각 / 취침 시각 / 기상 시각 / 컨디션(1~5) / 방 온도 / 방 밝기
- **포인트 규칙**
  - 기록 완료(무조건): +10
  - 취침 시각이 22:30 / 23:00 / 24:00 / 01:00 이전: +40 / +30 / +20 / +10
  - 취침 30분 전 화면 끄기: +15
  - 7시간 이상 수면: +10, 8시간 이상 수면: +15
  - 연속 기록 3일 / 7일 / 14일 달성: +20 / +50 / +100
  - 7일 연속 완주 보너스: +50
- **배지 큐브** — 9개 조건 달성 시 배지 획득
- **레벨** — 누적 포인트 300P마다 레벨업
- **데이터 분석** — 취침 시각대별 다음날 컨디션 평균 (3일 이상 기록 시 표시)
- **포인트 전환** — **300P = 1,000원**, "전환하기" 버튼으로 적립금(원)으로 전환

## 기술 구조

순수 정적 사이트(HTML/CSS/JS, 프레임워크·빌드 과정 없음)로, **GitHub Pages에 그대로
배포**할 수 있게 만들었습니다.

```
index.html      메인 앱 화면
login.html      로그인 / 회원가입 화면
css/style.css   스타일
js/points.js    포인트·배지·레벨·전환 계산 로직 (순수 함수)
js/store.js     localStorage 데이터 저장/조회
js/auth.js      비밀번호 해싱 (WebCrypto PBKDF2)
js/app.js       메인 화면 동작
js/login.js     로그인/회원가입 동작
```

### ⚠️ 로그인 방식에 대한 중요한 안내

GitHub Pages는 정적 파일만 제공하고 서버(백엔드/DB)를 실행할 수 없습니다. 그래서
이 앱의 "로그인"은 **실제 서버 인증이 아니라, 브라우저의 localStorage에 계정과
기록을 저장하는 방식**입니다.

- 데이터는 **같은 브라우저·같은 기기**에만 저장됩니다. 다른 기기/브라우저에서는
  같은 계정으로 로그인해도 데이터가 보이지 않습니다.
- 브라우저 저장공간(사이트 데이터)을 지우면 계정과 기록이 모두 사라집니다.
- 이 로그인은 "내 기록과 남의 기록을 분리해서 보여주는" 용도이지, 민감한 개인정보를
  보호하는 진짜 보안 인증은 아닙니다. 실제 서비스로 확장하려면 서버(DB) 기반
  인증이 필요합니다.

## 로컬에서 미리보기

의존성 설치 없이 Node.js만 있으면 바로 실행됩니다.

```bash
npm start
# http://localhost:5173 접속
```

> `index.html`을 브라우저로 직접 여는(`file://`) 방식은 비밀번호 해싱에 쓰는
> WebCrypto API가 보안 컨텍스트가 아니라서 동작하지 않을 수 있습니다. 반드시
> 위 명령처럼 로컬 서버를 통해 `http://localhost`로 접속하세요.

## GitHub Pages로 배포하기

이 저장소에는 `main` 브랜치에 push될 때 자동으로 GitHub Pages에 배포하는
GitHub Actions 워크플로우(`.github/workflows/pages.yml`)가 포함되어 있습니다.

1. 저장소 **Settings → Pages** 로 이동
2. **Source**를 **GitHub Actions**로 설정
3. `main` 브랜치에 push하면 자동으로 배포되고, 완료 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속할 수 있어요.

수동으로 배포하고 싶다면 Actions 탭에서 "Deploy to GitHub Pages" 워크플로우를
`workflow_dispatch`로 직접 실행할 수도 있습니다.
